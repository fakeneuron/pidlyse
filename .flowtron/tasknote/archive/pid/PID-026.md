# PID-026 | animated-icon

[← PLAN.md](../PLAN.md) · 🟢 In progress

## 🎯 Goal

Animate the menu-bar icon to reflect scan state — a visual cue (pulse / glyph change) when strays are found, beyond the current static badge count.

## ✅ Acceptance

- [ ] A one-shot pulse animation fires on the status-item icon when the stray count (`safe + review`) increases, including the 0→N transition.
- [ ] No pulse when the count is unchanged or decreases (e.g. after killing/clearing or a quiet rescan).
- [ ] The scanning glyph stays static (no rotation) — per scope decision.
- [ ] The pulse honors Reduce Motion (skipped when the OS setting is on; glyph + badge still convey state).
- [ ] `make build-release`/build succeeds and `make test` stays green.

## 🧩 Subtasks

- [ ] Add `lastStrayCount` tracking state to `AppDelegate`.
- [ ] In `updateIcon()`, compute `strayCount = safe + review`, trigger `pulse()` when it increases, then store the new value.
- [ ] Implement `pulse()` — a dip-and-restore `alphaValue` breath via `NSAnimationContext`, guarded by `NSWorkspace.shared.accessibilityDisplayShouldReduceMotion`.
- [ ] Build + run `make test`.
- [ ] Phase 4: amend SPEC.md §"Non-Goals (v1)" line 126 + §"Menu Bar States" to reflect the now-implemented animation; doc-drift sweep; close.
