**Discovery Notes:**

### Design decisions / explicit assumptions

- **Cache holds PID→name, not PID→ID.** The discovery line says "PID→name cache" and the `.3` UI wants the name. `docker stop` accepts a name as readily as an ID, so the kill path can `docker stop <name>` directly — this lets `findContainerID` (which returned an ID) be deleted outright rather than kept alongside a parallel name map. One map serves both the kill path and the future `.3` hint.
- **`docker inspect` `{{.Name}}` carries a leading `/`** (e.g. `/pg-db`), unlike `docker ps {{.Names}}`. The parser strips it so the cached name matches what the container panel already shows.
- **Match semantics unchanged.** The cache keys off `State.Pid`, the identical field `findContainerID` matched against. On Apple Silicon this is a LinuxKit-VM-internal PID that often won't match a host `ps` PID (the discovery's graceful-degrade caveat) — but I am preserving that behavior exactly, only moving *when* it resolves (scan time, once) vs. *per kill click*. No false promise: unmatched PIDs simply aren't in the map, exactly like the port/parent hints.
- **Plumbing via parameter.** `KillService` is a static enum with no `ScanEngine` reference, so the owner map is passed into `kill(_:containerOwners:onComplete:)` from the call sites (both have `engine` in scope). A `= [:]` default keeps the batch→single delegation clean and means "no owner resolved → fall through to POSIX" (safe graceful-degrade).
- **Adds one docker shell-out per scan.** `scan()` currently never calls docker; `DockerService.containerOwners()` adds a bulk `docker ps -q` + `docker inspect` each scan (≈120 s cadence). Acceptable and intended — it replaces the per-kill-click inspect (F9).
- **Test surface:** only the pure `DockerCore.parseContainerOwners` is unit-tested (in `DockerCoreTests`). The impure `DockerService.containerOwners()` and `ScanEngine` wiring are not — mirrors the existing convention (`listContainers`/`listeningPorts` have no unit tests).

Discovery surfaced no significant deviation → skip 🛠️.
