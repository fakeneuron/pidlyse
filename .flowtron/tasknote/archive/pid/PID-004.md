# PID-004 | kill-hardening

[← PLAN.md](../PLAN.md) · 🟢 In progress · 🔗 [[PID-003]]

## 🎯 Goal

Harden `KillService` so Docker processes route through `docker stop` instead of raw POSIX signals, and surface kill-flow edge cases (EPERM, already-gone) gracefully.

## ✅ Acceptance

- [ ] `KillService` routes `kind == .docker` through `docker stop <containerID>` when a matching running container owns that PID; falls back to SIGTERM→SIGKILL for daemon processes (com.docker.backend etc.) where no container match is found
- [ ] EPERM on `Darwin.kill` is detected rather than silently swallowed
- [ ] All existing `ScanEngineTests` still pass; `xcodebuild build` green

## 🧩 Subtasks

- [ ] Resolve Docker CLI path at runtime (check `/usr/local/bin/docker`; fall back to `/opt/homebrew/bin/docker`)
- [ ] Add `findDockerContainerID(for pid: Int32) -> String?` — `docker ps -q` + `docker inspect --format '{{.State.Pid}}'` cross-reference loop
- [ ] Add `dockerStop(containerID: String) -> Bool` — `docker stop <id>`, return success/failure
- [ ] Refactor `kill(pid:onComplete:)` → `kill(_ item: ProcessItem, onComplete:)` so the kind is visible; route `.docker` items through docker-stop-then-SIGTERM fallback
- [ ] Matching bulk refactor: `kill(pids:onComplete:)` → `kill(_ items: [ProcessItem], onComplete:)`
- [ ] EPERM handling — check return of `Darwin.kill`; if EPERM, call `onComplete` immediately (process stays visible on rescan, surfacing to the user that it's unkillable)
- [ ] Update `MenuBarView` call sites to pass `item`/`items` instead of `item.pid`
- [ ] `xcodebuild build` + test green

**Final Summary:**

Hardened `KillService` to route Docker processes through `docker stop` (via PID → container ID lookup using `docker ps` + `docker inspect`) before falling back to SIGTERM→SIGKILL, preventing raw signals from bypassing Docker's container shutdown lifecycle. Added EPERM detection: when `Darwin.kill` is blocked by permissions (e.g. root-owned Docker daemon), `onComplete` fires immediately so the caller rescans and the process stays visible — a clean signal that it's unkillable without privileges.
