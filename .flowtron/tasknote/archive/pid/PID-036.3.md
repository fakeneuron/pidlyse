**Discovery Notes:**

**Surface to wire:**
- `MenuBarView.reasoningBlock(item:isOld:)` (`Pidlyse/MenuBarView.swift:259-273`) — the expansion-gated block. Currently: an orange `criterionTag` HStack (`no tty` / `orphan` / `old`) + one monospaced secondary line (`tty · ppid · age`). Provenance hints slot **below** the raw-values line as new secondary lines. The view already `import PidlyseCore` and holds `engine`.
- `PortRegistry.listeningPorts(lsofOutput:) -> [Int32: Set<Int>]` (`PortRegistry.swift:119`) — PID→registered-ports map from `.2`. Impure (`lsof`), so it runs **at scan time** in `ScanEngine`, not in the view (layering rule). Published on the engine for the view to read.
- `ScanCore.parentCommand(ofPPID:in:) -> String?` (`ScanCore.swift:80`) — pure, operates on `[ProcessItem]` = `engine.items`, already in the view's hand. **Zero plumbing** — the view calls it directly. Returns `nil` for launchd (`ppid==1`) and non-candidate parents → the common, gracefully-degrading case.

**Single-lsof plumbing (avoid double shell-out):** `enumerate` internally calls `PortRegistry.listeningPIDs()` (one `lsof`) when `registeredPIDs` is nil. `listeningPorts()` is a second `lsof`. Since `Set(listeningPorts().keys) == listeningPIDs()` (same parse, same registered-port filter via `parseListenerLine`), compute `listeningPorts()` once in `scan()` and pass `registeredPIDs: Set(portMap.keys)` into `enumerate` — one `lsof`, demotion behavior identical, map published for the UI.

**Archive precedents:** [[PID-008]] (reasoningBlock + `criterionTag` + secondary-text — the rendering vocabulary), [[PID-036.1]] (expansion-gated, port-number-only, ppid-over-scan-set scoping), [[PID-036.2]] (the two resolvers + their nil/empty degrade semantics), [[PID-35.3]] (`startTimeProvider` scan-time-provider precedent — same shape as publishing a scan-time port map).

The parent hint is plainly descriptive. (Considered a port badge — rejected to keep the orange row semantically clean. This is expansion-gated detail text, so two extra secondary lines read fine.)
