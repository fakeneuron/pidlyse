# PID-073 | inspector-ppid-grouping

[← PLAN.md](../PLAN.md) · 📌 Sidequest (filed 2026-09-25)

## Idea

The expanded row inspector's `Text("tty \(item.tty)  ·  ppid \(item.ppid)  ·  age …")`
in `MenuBarView.swift`'s `reasoningBlock` interpolates `item.ppid` directly
inside a `Text` string literal, routing it through SwiftUI's
`LocalizedStringKey` number formatting — the same thousands-separator bug
PID-070 just fixed for the always-visible row PID (`Text(verbatim:)` fixes
it there). Lower visibility (only shows when a row is expanded), so left
out of PID-070's scope. Fix: `Text(verbatim:)` on that line too.
