# PID-087 | spaced-path-names

[← PLAN.md](../PLAN.md) · 📌 Sidequest (filed 2026-10-17)

## Idea

`ProcessItem.displayName` misnames commands whose path contains a space: `ps` prints argv unquoted, so `/Users/me/My Project/node_modules/.bin/vite` splits at the space and the name derives from the wrong token. A pure parse of the `ps` string cannot fix it; the fix reads real argv (`sysctl` `KERN_PROCARGS2`) at scan time. Surfaced by the PID-086.3 external review, note #1.
