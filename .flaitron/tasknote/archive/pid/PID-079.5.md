## 🎯 Goal

Make `pidlyse clean` return a failing exit status whenever its sweep has any non-`gone` outcome, and document that contract for terminal and Raycast users.

## ✅ Acceptance

- [x] The CLI maps a clean report to exit 0 only when every requested item is `gone`, otherwise exit 1 — `swift test --package-path Packages/PidlyseCore --filter CLICoreTests`
- [x] `pidlyse clean` uses that shared exit-status decision after printing its existing per-item output and summary — `rg -q 'exit(commandClean())' Packages/PidlyseCore/Sources/PidlyseCLI/main.swift && rg -q 'CLICore.cleanExitStatus' Packages/PidlyseCore/Sources/PidlyseCLI/main.swift`
- [x] Raycast and README CLI guidance state the partial-clean failure behavior — `rg -q 'exit status 1' README.md integrations/raycast/README.md integrations/raycast/clean-safe-strays.sh`
