**Discovery Notes:**

**Live evidence (2026-10-16, `swift build -c release` CLI, `pidlyse list`).** 31 candidates: 9 Docker Desktop helpers (`com.docker.backend`/`vmnetd`/`build`/`virtualization`/`Docker Desktop` + Frameworks helpers, cwd label `Data`), 8 dev servers (5 in terminal tabs via `just`, tty `ttys0NN`; 3 started by Claude Code background shells `zsh[??]` under a live `claude[ttysNNN]`), 14 playwright-mcp (each under a live `claude`/`grok` tty). An ancestor walk of every non-Docker row reaches `Terminal.app → login → -zsh(tty)`: nothing is detached.

**Session-ended rule (designed from that walk).** A row's session has ended when no terminal or app still holds it: the row root has no tty, and walking ancestors from its ppid reaches launchd (pid 1) without passing an **anchor**, meaning a node with a controlling tty or a process inside a `.app/` bundle (Terminal, iTerm, VS Code, Claude desktop). Covers the plain orphan (`ppid == 1`) and the common Claude-background case. When the agent session exits, its `zsh[??]` is reparented to launchd while `vite` keeps its `just` parent, so `ppid == 1` alone misses it. A missing table entry mid-walk returns `false` (unknown → Running). With an empty table, only the direct-orphan case can fire. This needs `tty` and the full `comm` path in the process table, so `AncestryResolver` reads `pid=,ppid=,tty=,comm=`.

**Verdict design.**

- Precedence `sessionEnded` > `duplicate` > `idle` > `running`. Duplicate outranks idle because it names the more actionable fact (a newer copy exists).
- **Idle** — not session tooling, row has no tty, `elapsed ≥ 2 h` (`StrayVerdict.idleAge`), and quiet CPU. The app feeds `ScanHistory.isSustainedLowCPU`; the one-shot CLI feeds a single-sample `cpuPercent < ScanHistory.defaultLowCPUThreshold`.
- **Duplicate** — not session tooling, cwd resolved, and another row has the same `RespawnHistory.Signature(command:cwd: fullPath)` with strictly smaller `elapsed`. The older copy is flagged; the newest stays Running. Exact cwd (not project root) is conservative: two `node server.js` in sibling subfolders of one repo never collide. Today's `judedelparte` vite pair (cwds `judedelparte` vs `judedelparte/frontend`) is therefore *not* flagged, an accepted miss.
- **Session tooling** (`playwrightMCP`, `mcpServer`, `chromeHelper`) is never idle or duplicate. These live exactly as long as their agent session, are quiet by nature, and every agent session runs its own copy (today: two `fakeneuron` playwright-mcps under different live sessions). Their only stray signal is session ended.
- Group rows: the verdict reads the root's identity (ppid/tty/elapsed), the summed group CPU (what `ScanHistory` already records), and the representative command.

**Sweep set.** `ScanPipeline.isSweepable(verdict:riskTier:isProtected:killability:)` = stray ∧ `riskTier != .high` ∧ ¬protected ∧ killable. `ScanEngine` adds respawner / EPERM (through `killability`) and kill phase. Consequence: a session-ended vite (strong stray → moderate) is swept; a session-ended `wrangler dev` (`.node` → always high) is listed but not swept; the external launchers (`pidlyse://clean`, Shortcuts) now reach moderate-tier strays in Needs Review, the contract change `.1` assigned here.
