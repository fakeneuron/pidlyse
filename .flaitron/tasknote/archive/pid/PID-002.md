- **Orphan signal on macOS:** when a process's parent dies, the kernel reparents it to `launchd` (pid 1). So "parent dead → orphan" ≡ `ppid == 1`.

**Risk algorithm (deterministic, testable):** base risk by kind, adjusted by signals.
- docker / uvicorn → always `high` (real dev infra; docker also needs `docker stop` not raw kill — flagged for [[PID-005]]/PID-004).
- test runners (pytest/vitest/jest/playwrightTest), playwrightMCP, chromeHelper → `easy` only when **strong stray** (no TTY ∧ orphan (ppid==1) ∧ old (elapsed ≥ threshold)); else `moderate`.
- npm / other → `moderate` when strong stray, else `high`.
- `bucket = (riskTier == .easy) ? .safe : .needsReview`.

**Validated against live `ps`:** docker daemon (ppid 1, 12d, ??) → docker/high/needsReview ✓; `npm run dev` (ppid 1, 30m, ??) → npm/moderate-or-high/needsReview ✓; Chrome under `ms-playwright-mcp` user-data-dir → chromeHelper/needsReview (parent alive) ✓.
