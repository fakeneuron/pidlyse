**Shared design surface inventoried:**
- `ProcessItem` (`Packages/PidlyseCore/Sources/PidlyseCore/ProcessItem.swift:73-90`) — stores `pid, ppid, command, elapsed, tty, kind, riskTier, cpuPercent, rssKB, startTime`. `ppid` + `command` already captured by the scan; **no** port-number or docker field, **no** free-text "reason" field on the model (reasoning is derived at display time).
- Row UI: `MenuBarView.reasoningBlock(item:isOld:)` (`Pidlyse/MenuBarView.swift:259-273`), rendered inside the `info.circle` expansion. Already prints `tty · ppid · age` + orange `criterionTag` badges (`:275-282`, `.caption2`/`.secondary`). **New hints slot here** — established per-row-hint pattern from [[PID-008]].
- `PortRegistry` (`Packages/PidlyseCore/Sources/PidlyseCore/PortRegistry.swift`): `listeningPIDs() → Set<Int32>` (`:75`) returns **PIDs only** — no PID→port-number mapping; `parsePIDAndPort` (`:94`) parses a line but only the PID is retained (`:128-130`). `registeredPorts` is a bare `Set<Int>` — **no port→project-name map** exists (names live in CLAUDE.md prose / user JSON per [[PID-025]]).
- ppid→parent: trivial in-memory lookup — parent process is almost always present in the same scan result set (`ScanCore` returns all `ps -axww` processes). `isOrphan` (`ppid == 1`) already exists.
- Docker ownership: `KillService.findContainerID(for:)` (`Pidlyse/KillService.swift:149-164`) — `docker ps -q` + bulk `docker inspect --format "{{.Id}}\t{{.State.Pid}}"`; **on-demand at kill only, no cache**, flagged O(n)-per-call smell **F9** in [[PID-35.1]]. Unsafe to call per-row/per-scan without a cache/provider.
- Layering (per CLAUDE.md): pure resolver logic → `PidlyseCore`; impure `docker` CLI → app-side `DockerService`. Scan-time providers are injected into `ScanCore` (precedent: `startTimeProvider` from [[PID-35.3]]).
- SPEC contract: `SPEC.md:98` ("Why is this here?" expands inline classification reasoning) + `:102-114` (port registry demote). **No provenance-hints section** — an impl child updates `SPEC.md`.

**Archive precedents:** [[PID-008]] (per-row reasoningBlock expander pattern — the rendering precedent), [[PID-005]]/[[PID-025]] (PortRegistry = port→project lookup surface; ports demote at classification time, not stored per-row), [[PID-13.3]] (kind detection = pure substring match), [[PID-28.2]] (Container model deliberately carries **no** host PID), [[PID-35.1]] (F9: findContainerID O(n)), [[PID-35.3]] (`startTimeProvider` injection precedent for scan-time providers).
