# PID-099 | pid-keyed-session-caches

[← PLAN.md](../PLAN.md) · 🟢 In progress · 🔗 [[PID-52.3]] [[PID-62.3]] [[PID-62.5]] [[PID-098]] [[PID-103]]

## 🎯 Goal

Key `ScanEngine`'s session-long open-files cache and dismissal set by pid + scan-time start time, so a recycled PID neither shows the previous process's open files nor stays hidden by an earlier "Ignore for session".

## ✅ Acceptance

- [x] A dismissal hides only the dismissed identity: the same PID with a different start time reappears on the next scan, in core (`ScanCore.enumerate`) and in the app's publish-time re-filter — `swift test --package-path Packages/PidlyseCore` + `make test` (new `ScanCoreTests` + `ScanEngineLifecycleTests` cases)
- [x] The open-files cache returns a list only for the identity it was fetched for, and a recycled PID re-fetches — `make test` (new `ScanEngineLifecycleTests` case via an injected open-files loader)
- [x] Existing dismissal behaviour holds: dismiss-during-flight stays hidden, ↺ `rescan()` clears, dismissing a group root drops the whole group — `make test` (updated `testDismissDuringFlightStaysHiddenUntilRescan`, `testEnumerate_dismissedRoot_dropsWholeGroup`)

External review (`/code-review medium`), all **notes**:
1. A dismissal recorded with a nil start time no longer matches a later timed read of the same process (or the reverse) — **accepted**: `KillCore.startTime` reads sysctl `kinfo_proc` and returns nil only when the process is gone, so a live row flipping nil ↔ value is not a realistic state; widening nil to a wildcard would bring back the PID-reuse hiding this task removes.
2. Overlapping fetches for an old and a recycled identity on one PID: last writer wins, the inspector may show no list until re-expand — **accepted** (logged as an assumption in Discovery): it degrades to "no list", never to wrong files.
3. `lsof` runs after the scan, so a PID recycled in between gets the new process's files under the old identity — **fixed**: `liveOpenFiles` re-reads `KillCore.startTime` after `lsof` and returns an empty list on a mismatch.
4. The cache keeps entries for dead PIDs all session — **accepted**: unchanged from PID-52.3's "bounded to the rows the user has inspected"; one entry per PID, overwritten on a recycled fetch.
5. `isDismissed` doc called its map "the `killDeniedIdentities` shape" though nil handling differs — **fixed**: the doc now states the difference.
6. A third pid + start-time encoding next to `StrayIdentity` / `killDeniedIdentities` — **deferred** (Best Practices Review already named the consolidation as unrelated cleanup).
7. AGENTS.md's init-seam list lacked the new loader — **fixed**.
