**Implementation Notes:**

`Shell.swift` already uses `NSLock` for in-process state. Nothing in the repo took a cross-process file lock, so `append` grew one: `NSLock`, then `flock(LOCK_EX)` on the sibling `<log>.lock` file, then a re-read, merge, and the existing atomic `save`. `flock` is process-owned on macOS, which is why the in-process lock is still there. An empty append returns before either lock, so it still creates nothing. `save` stays the raw writer. A test-only sleep inside the locked section, the same shape as `Shell.deadlineOverride`, forces the overlap the thread test checks. No downstream-impact reconcile: the JSON format and the two callers are unchanged.
