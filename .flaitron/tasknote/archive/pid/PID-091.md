# PID-091 | spaced-display-path

[← PLAN.md](../PLAN.md) · ✅ Completed 2026-10-18 · 🔗 [[PID-087]]

## 🎯 Goal

Make `ProcessItem.displayPath` show the right `parentDir/executable` when the executable path contains a space, by reading the scan-time `argv[0]` instead of the first space-split token of `command`.

## ✅ Acceptance

- [x] A spaced executable path with argv known (`/Applications/My App.app/Contents/MacOS/My Tool`) displays as `MacOS/My Tool` — `swift test --package-path Packages/PidlyseCore --filter ProcessItemTests`
- [x] With `argv` nil (or empty), `displayPath` is unchanged: first token of `command` — the existing `testDisplayPath_*` cases still pass
- [x] Full core suite and app build stay green — `make test`

## 🧩 Subtasks

- [x] `displayPath`: take the executable from `argv?.first` when present and non-empty, else the first token of `command`
- [x] Add tests: spaced path via argv, argv-nil fallback to the `ps` split, empty argv fallback
- [x] Run targeted tests, then `make test`
