**Name rules (pure, in order):** custom label → Chrome helper keeps `kind.label` (its path has spaces) → shell `-c` recurses on the last `&&`/`;` segment → skip leading `VAR=value` / `env` → interpreter (node, deno, bun, python*, ruby, tsx, ts-node) skips its flags (and `-r`/`--require`/`--import`/`--loader` values; `python -m mod` → mod) to the script → script inside `node_modules/<pkg>/` (not `.bin`) names the package, otherwise the script basename; non-script leaf names the bin → one `[a-z][a-z0-9-]*` subcommand appended (`run` / `exec` / `npx` take their target, version stripped) → friendly table: vite (no sub / dev / serve) "Vite dev server", next dev "Next.js dev server", next-server "Next.js server", astro dev "Astro dev server".
