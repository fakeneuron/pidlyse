**Discovery Notes:**

- Published hash for `gitleaks_8.30.1_darwin_arm64.tar.gz` (from the release's `gitleaks_8.30.1_checksums.txt`): `b40ab0ae55c505963e365f271a8d3846efbc170aa17f2607f13df610a9aeb6a5`. Independently confirmed by hashing the tarball downloaded locally — identical. `shasum -a 256 -c` prints `OK` on it and exits 1 on a wrong hash.
- Injection reality check: `github.ref_name` for a tag push is constrained by git ref-name rules, but those still allow `$`, backticks, `;`, `(`, `)` — so the interpolation is a real (if low-severity, since only users who can push tags can reach it) shell-injection shape. Hence `env:` + a quoted variable.
- Placement: `release.yml` already puts `permissions:` between `on:` and `jobs:`; `test.yml` gets the same position.
