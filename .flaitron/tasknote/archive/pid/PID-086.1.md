Nothing on the list is a forgotten process. The app is behaving as a **status locator**: pattern-match → list, with the stray signals (no tty / orphan / old) only feeding the risk tier, and the "attached to a live parent session" fact never surfaced.

**Identity problem.** Row line 1 is `PID 12345` (monospaced caption); line 2 is the project label (or `displayPath`). *What* the process is — Vite, wrangler dev, a scraper script — lives only in the kind-group header, and `kind` is coarse (`wrangler dev` and `import-scraper.js` both read `Node`). The command already carries a better name (script basename / bin name + subcommand).
