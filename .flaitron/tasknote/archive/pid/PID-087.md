# PID-087 | spaced-path-names

[← PLAN.md](../PLAN.md) · ✅ Completed 2026-10-17 · 🔗 [[PID-086.3]]

## 🎯 Goal

Make `ProcessItem.displayName` name a process correctly when its executable or script path contains a space, by reading the real argv (`sysctl` `KERN_PROCARGS2`) at scan time instead of re-splitting the unquoted `ps` string.

## ✅ Acceptance

- [x] A pure `KERN_PROCARGS2` buffer parser returns the exact argv (spaces inside an argument preserved), and `nil` for a malformed buffer — `swift test --package-path Packages/PidlyseCore --filter KillCoreTests`
- [x] `displayName` names `node /Users/me/My Project/node_modules/.bin/vite` as `Vite dev server` when argv is known, and is unchanged (same results as today) when argv is absent — `swift test --package-path Packages/PidlyseCore --filter ProcessItemTests`
- [x] The scan captures argv through an injectable provider and keeps it only when it agrees with the `ps` command line; `collapseTrees` carries the representative's argv — `swift test --package-path Packages/PidlyseCore --filter ScanCoreTests`
- [x] `ScanPipeline` wires the live provider (`KillCore.argv`) so app and CLI both get it — `grep -q 'argvProvider: KillCore.argv' Packages/PidlyseCore/Sources/PidlyseCore/ScanPipeline.swift`

`KERN_PROCARGS2` buffer layout: `int32 argc`, `exec_path\0`, zero or more `\0` padding, then `argc` NUL-terminated argv strings, then the environment. Padding is skipped once, then exactly `argc` strings are read so an empty argument survives.

**Implementation Notes:**

- `KillCore.argv(of:)` (`sysctl` `KERN_PROCARGS2`, size query then fetch) and pure `KillCore.parseProcArgs(_:)`.
- `ProcessItem.argv: [String]?` (init param last, default nil); `displayName` passes it to `name(of:argv:)`, which tokenises from it when present. The `uv run` / `poetry run` recursion passes its tokens on as argv so a spaced path survives it. The `sh -c` recursion re-parses script *text*, where a spaced path is shell-quoted and not recoverable from argv; documented limit, unchanged.
- `ScanCore.enumerate` / `makeItem` take `argvProvider`; argv is kept only when `argv.joined(" ")` (whitespace-trimmed) equals the `ps` args, so a recycled PID or rewritten title falls back to the old string behaviour. `collapseTrees` carries the representative's argv.
- `ScanPipeline.run` passes `argvProvider: KillCore.argv`, so the app and the CLI both get it. Live check: `pidlyse list --all` named `node "/tmp/pid087 smoke dir/node_modules/.bin/vite"` as `Vite dev server` (the old split gave `pid087 smoke`).
